## Reproduce the package locally

Use Node 22.19 or newer within Node 22 and an application checkout containing
the reviewed 0.7.0 source. Run these commands from this plugin repository:

```powershell
$env:RIM_APP_ROOT = 'C:\path\to\rank-in-maps-ctbmarketing'
node --experimental-strip-types "$env:RIM_APP_ROOT/packages/agent-tool-contract/scripts/emit-agent-plugin.mjs"
node --experimental-strip-types "$env:RIM_APP_ROOT/packages/agent-tool-contract/scripts/emit-agent-plugin.mjs" --check
node --experimental-strip-types scripts/sync-app-package.mjs
node --experimental-strip-types scripts/validate-contract.mjs
node --experimental-strip-types "$env:RIM_APP_ROOT/packages/agent-tool-contract/scripts/package-agent-plugin.mjs"
```

The final command is the application script behind `pnpm agent-plugin:package`.
It validates the canonical file map and generated bytes, then writes
`output/openai-plugin/rank-in-maps-0.7.0.zip` and its `.sha256` sidecar in the
application checkout. Those local outputs are ignored. Sorted entries and
fixed timestamps make identical source produce identical archive bytes.

Build the submission ZIP through that script rather than archiving this whole
repository. The plugin-owned Last 30 Days workflow remains here unchanged;
it is not silently added to the canonical OpenAI ZIP.
